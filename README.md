# Web Technologies Website — Historical Iteration

This repository contains an earlier iteration of Omar Gouda's Turkish-language web technologies learning website. It is retained for historical reference, not presented as a separate portfolio project.

**Selected maintenance repository:** [nanafi23/omargoudaweb](https://github.com/nanafi23/omargoudaweb).

Please use the maintenance repository for the project overview, setup instructions and future improvements. Historical layouts and file paths differ between copies; no claim is made that every file here is identical to the maintenance copy.

## Original implementation

A frontend coursework website using HTML, CSS, JavaScript and Bootstrap-based styling. It introduces web development topics and provides learning-resource links. Static forms do not provide secure server-side authentication or message delivery.

## Maintenance repair

The missing stylesheet was restored from the related historical `omar_gouda` layout. Local image and favicon references now match the files included here.
